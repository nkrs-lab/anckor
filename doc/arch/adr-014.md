## use predefined mapping for kernel syscalls and gave it to the linker script

Syscalls are statically mapped. This is a big security issue as this design is subject to **return-to-libc** attack and should not be used in a stable release. 

But this is convenient for a first release as we just define syscalls address in a linker script :

```C
ax_task_create = 0x800fe000;
ax_task_get = 0x800fe008;
ax_task_destroy = 0x800fe010;
ax_task_yield = 0x800fe018;
...
```

Partitions can then call kernel routine through these calls:

```C
               │               │    
               │       .       │    
               │       .       │    
               │       .       │    
               │               │

               │               │

    0x80101000 ├───────────────┤   │
               │               │   │
```

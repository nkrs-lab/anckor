# Title

Specify executable sections as loadable

# Context

The **.syscall_wrappers** section is not extracted by objcopy.

# Decision

We need to add the "a" flag to specify that the section is allocatable. This marks the section the section as loadable in the **.elf** file :

```C
.section .syscall_wrappers, "ax"
```

We also need to add appropriate flags in the linker script :

```C
PHDRS
{
  ...
  syscall_wrappers PT_LOAD FLAGS(5);   /* PF_R|PF_X */
}
```

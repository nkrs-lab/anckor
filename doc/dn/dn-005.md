# Title

Use executable section at compile time

# Context

Syscalls user code is placed in a dedicated section **.syscall_wrappers**. At compile time, an error occured as the code was not compiled.

# Decision

We need to add the "x" flag to specify **at compile time** that the section is executable. GCC needs to know that at the compilation stage, not the linking stage :

```C
.section .syscall_wrappers, "x"
```
